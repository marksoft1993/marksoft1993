## Обо мне

Работаю с **VB.NET и .NET**, десктопными интерфейсами на **AvaloniaUI**, компьютерным зрением и автоматизацией Android через **ADB**. Меня интересует связка интерфейса, распознавания изображения и сценариев действий: от наблюдения за состоянием приложения до выполнения повторяющихся задач.

Мой основной проект — **«Эрида»**, ассистент для Kingdom Guard.

## Главный проект

### Эрида · Kingdom Guard Assistant

**Десктопный ассистент для Windows, автоматизирующий рутинные действия в Kingdom Guard.**

Фарм, сбор наград, задания, магазин и сценарии KvK — в одном приложении. Доступные возможности зависят от подписки.

[![Project](https://img.shields.io/badge/Проект-Kingdom--Guard--Bot-6366F1?style=flat-square&logo=github&logoColor=white)](https://github.com/marksoft1993/Kingdom-Guard-Bot)
[![Website](https://img.shields.io/badge/Сайт-24erida.ru-0F766E?style=flat-square)](https://24erida.ru)

Публичный репозиторий содержит описание проекта и инструкцию по началу работы. Исходный код приложения не опубликован.

## Направления работы

- **Десктопные приложения:** интерфейсы и прикладная логика на .NET.
- **Компьютерное зрение:** распознавание визуальных объектов с YOLO.
- **Android и ADB:** взаимодействие с устройствами и автоматизация действий.
- **Автоматизация:** инструменты для выполнения повторяющихся сценариев.
